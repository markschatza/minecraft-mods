# Contributing

This repo is meant for learning together.

## Definition Of Done

A change is done when:

- The code builds.
- Minecraft opens with `runClient`, if the change affects gameplay.
- The change is committed with a clear message.
- The other person can explain what changed.

## Code Style

- Keep changes small.
- Use clear names.
- Prefer simple Java over clever Java.
- Add comments only when they explain why something is done.

## Good First Pull Requests

- Change a command message.
- Add one new quest.
- Add one new `/academy` subcommand.
- Improve a setup note after you hit a real problem.
