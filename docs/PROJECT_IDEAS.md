# Project Ideas

Start with commands because they are easy to test. Move into items and blocks after the Java basics feel less strange.

## Beginner

- Add `/academy roll` to roll a number from 1 to 20.
- Add `/academy coin` to print heads or tails.
- Add `/academy compliment` to print a random message.
- Add `/academy challenge` to give a Minecraft build challenge.

## Intermediate

- Add command arguments, like `/academy say hello`.
- Save a score in memory while the game is running.
- Register a custom item.
- Register a custom block.
- Add recipes and loot tables with JSON files.

## Advanced

- Add a custom creative tab.
- Add a block that does something when right-clicked.
- Add a custom status effect.
- Add a tiny server-side minigame.
- Add automated tests for helper methods.
